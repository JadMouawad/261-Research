# 261-Research

This repository contains our reinforcement learning presentation source files and final video deliverables for the research project submission.

## Main Presentation Videos

- `deliverables/final_presentation/rl_segments_01_to_06_full_1080p60.mp4`
- `deliverables/final_presentation/RL_Person2_Scenes7-12.mp4`

## Repository Structure

- `deliverables/final_presentation/`
  - Final videos used in the submission/presentation.
- `deliverables/segment_videos/`
  - Individual segment exports for Part 1.
- `segments/`
  - Manim source code for Part 1 segments (Scenes 1-6).
- `manim_rl_presentation/`
  - Manim source code for Part 2 scenes (Scenes 7-12).
- `project_files/`
  - Supporting project files (scene concatenation list, etc.).

## Notes

- Legacy and cache folders were removed to keep the repository clean and easy to navigate.
- Generated render caches are ignored through `.gitignore`.
